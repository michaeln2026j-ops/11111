\section*{Highlights}
\begin{itemize}
\item Pass overlap is calibrated from logged runs to bound the chance of a missed strip
\item The same runs state the miss probability of any margin or gap tolerance chosen
\item Fields without history are calibrated across fields with a vehicle model
\item Simulation: miss level met; 4--55\% less overlap than two conformal planners
\item Zero-miss margins paid off only if misses cost about 40--90 times overlap
\end{itemize}
