\section*{Highlights}
\begin{itemize}
\item A method sets pass overlap so that missed strips occur with a chosen probability
\item Each logged run is reduced to one coverage score that decides complete coverage
\item Fields without history are calibrated across fields with a vehicle model
\item Simulation: target held; 4--55\% less overlap than conformal planners
\item A zero-miss margin pays off only if a miss costs 30--100x an overlap
\end{itemize}
