# 事先声明：低数据实验 E-low（理论枢轴 + 跨田块共形，CE-EVT）

本文件在任何 E-low 结果产生之前提交。提交之后对方法、指标和判据的任何改动，都要在结果中单列说明。

## 1. 问题

现有的共形认证方法，包括本文的 CE、CE+ 和对照方法 CPP、Lindemann，都需要**目标田块自己**的大量历史作业。$\varepsilon=0.1$ 时：

- 边际版至少需要 9 次，否则分位数为 $+\infty$；
- PAC 版（$\delta=0.1$）至少需要 22 次。

实际中一块田一年只作业几次。现实的数据形态是：许多田块，每块只有一两次历史作业，而新田块一次也没有。

## 2. 方法 CE-EVT（本文）

对每块田 $f$ 和它的参考计划 $\pi_f(\lambda_0)$，第 1–4 层理论（`experiments/evt_theory.py`）给出作业级分数 $U$ 的预测分布 $\hat F_f$。这个预测**不使用任何作业数据**，只用控制器参数、地形和作业条件的分布。

1. **枢轴化。** 校准田块 $f_i$ 的一次历史作业，分数为 $S_i$，取 $V_i=\hat F_{f_i}(S_i)$，即概率积分变换。
2. **跨田块共形。** $v^*$ 取 $\{V_i\}$ 的共形分位数：边际版取第 $\lceil(n+1)(1-\varepsilon)\rceil$ 个次序统计量；PAC 版取满足二项条件的次序统计量。
3. **部署。** 对新田块 $g$，取余量 $\lambda_g=\hat F_g^{-1}(v^*)$，部署 $\pi_g(\lambda_g)$。

**有效性。** 田块从同一总体独立抽取，每块田只用一次作业，所以 $(V_1,\dots,V_n,V_{\rm new})$ 可交换。由此得到边际（或 PAC）保证 $P(S_{\rm new}\le\lambda_g)\ge1-\varepsilon$。这个保证**不依赖理论是否准确**：理论误差只影响效率。部署到 $\pi_g(\lambda_g)$ 时，用定理 4.3 的迁移。

**效率来源。** 理论越准，$V$ 在不同田块上的分布越接近同一个均匀分布，$\lambda_g$ 就越贴近该田自己的 0.9 分位数。原始分数则因田块大小、坡度和行数不同而分布不同，合并后会变保守。

## 3. 实验设计

- **工况**：R1、R2、R3；栈为 BCD + LQR-I；$\varepsilon=0.1$，PAC 的 $\delta=0.1$。
- **田块**：全新田块，v1–v8 都未使用：
  - R1 用 wheat 第 80–139 块；
  - R2 用 paddy（$w=1.5$）第 80–136 块；
  - R3 用 paddy（$w=6$）第 80–110 块。
- **留一法**：每块测试田依次作为新田块，其余田块各提供**一次**历史作业，作业在该田的参考计划上执行，参考余量 $\lambda_0$ 同 CE+，由训练田块确定。校准田块数 $n_{\rm cal}=\min(30,\ \text{池大小}-1)$，随机抽取。
- **评估**：每块测试田用 200 次全新作业评估部署计划的 P(无漏) 和重叠率，并计算每田 oracle（与 v6–v8 相同的定义）。

**对照方法**（数据完全相同，即每块校准田一次作业，目标田零次）：

| 方法 | 说明 |
|---|---|
| 合并共形（原始分数），边际版和 PAC 版 | 经典的分布无关跨田块做法：所有田块用同一个余量，取原始分数 $S_i$ 的共形分位数 |
| 农户调参全局重叠 | 行业做法，与 v6–v8 相同 |
| 规格重叠（2 × p2p） | 行业做法 |

**消融**（不参与主张）：

- 理论直接预测、不做共形：$\lambda_g=\hat F_g^{-1}(1-\varepsilon)$，没有保证；
- 只用规模律归一化的合并共形：$S/\sqrt{2\log N_f}$。

## 4. 指标与判据（固定）

- **有效性**
  - 边际类方法：所有测试田合并后的 P(无漏) 不显著低于 0.9（单侧二项检验，按田块聚类）。
  - PAC 类方法：不达标田块数服从 $\mathrm{Bin}(F,\delta+\alpha)$ 的上界检验，同 `theory_v8.md` 命题 4。
- **主效率指标：多出的重叠**，即测试田上部署计划的主作业区重叠率减去 oracle 重叠率，取所有测试田的平均，单位为百分点。
- **"提升 10%"的定义**：在同一保证类别（边际对边际，PAC 对 PAC）内，与**有效的**最强对照方法相比，
$$\text{相对提升}=\frac{\overline{\text{多出的重叠}}_{\rm 对照}-\overline{\text{多出的重叠}}_{\rm CE\text{-}EVT}}{\overline{\text{多出的重叠}}_{\rm 对照}}\ \ge\ 10\%.$$
  显著性检验用按田块配对的单侧 Wilcoxon 检验，对"工况 × 对照方法"做 Holm 校正，水平 0.05。
- **同时报告**：绝对重叠率的相对差。如果它低于 10%，也要如实写出。
- **主张**：在 R1、R2、R3 每个工况下，CE-EVT 有效，并且按上述定义比有效的最强对照提升 $\ge10\%$。任何一个工况不满足，就如实报告"不成立"。
