# 事先声明（v3）：理论必要性、"每格不输"与重复校准抽样下的有效性

本文件在 v3 测试田块（各工况第 5–19 块）的任何计算之前提交。

## 0. 要彻底解决的四个问题（来自 v2）

1. **理论的必要性。** 在单一工况内，理论枢轴相对规模律在 R1 PAC 上的优势不显著（p = 0.079）。审稿人会问："只为算一个分位，简单方法行不行？"
2. **边际覆盖率偏低**（R1 为 0.844）。根源是 v2 只有**一次**校准抽样：给定校准集，覆盖率服从 Beta 分布，标准差约 0.05。
3. **不是每格都赢。** R2 和 R3 的 PAC 格子没有提升。命题 8 说明这是信息极限；但方法本身应当**事先**知道哪里会赢，并在不会赢的格子自动退回经典做法。
4. **"同等覆盖率下的比较"** 尚未完成。

**设计依据。** 下面的数字只用 v1、v2 的**已公开**数据，v3 测试田块未参与。
- **混合机队**：校准池混合三种机器配置（RTK 3 m / RTK 1.5 m / DGPS 6 m）时，各预测器对每田最优余量 λ* 的 log 误差标准差：

  | 预测器 | 误差 |
  |---|---|
  | 理论（零数据） | **0.047** |
  | 按幅宽归一化 | 0.388 |
  | 规格 × 规模律 | 0.433 |
  | 数据驱动：田块特征 + 机器配置，147 块田每块一次作业训练 | 0.136 |
  | 同上，但用每田数百次作业的 λ* 训练（现实中拿不到） | 0.054 |

- **单一工况内**，理论相对规模律的优势小。见 `results/lowdata_v2/feature_pivot.txt` 和 `feature_learning_curve.txt`。

## 1. 数据

- **测试田块（全新）**：每个工况第 5–19 块，按 `core.load_fields(seed=0)` 的顺序，共 3 × 15 = 45 块。
  - 这些田块在 v3–v6 的系统实验中出现过（CE/CE+ 需要目标田数据，回答的是另一个问题）。
  - **E-low 系列的任何设计或分析都没有用过它们。**
- **校准池**：
  - 同工况场景：v2 田块（第 50–79 块）中同工况的 30 块，每块一次历史作业，阶段 A 已存在。
  - 混合机队场景：v2 的全部有效田块（约 89 块）。
- **训练池**（只用于门控和 CQR 拟合）：v1 田块（第 80 块及以后，147 块），与校准池、测试田块都不相交。

## 2. 方法（所有方法都是尺度枢轴 λ_g = q_g · t，t 为校准池上 S/q 的共形分位）

| 名称 | q_f |
|---|---|
| 原始合并 | 1 |
| 规模律 | √(2 log N_f) |
| 规格 × 规模律 | p2p_f · √(2 log N_f)（仅混合机队场景有区别） |
| CQR（Romano 等 2019 型） | 田块特征 + 机器配置（log w、log p2p）的岭回归，目标为 log S，在训练池上**每田一次作业**训练 |
| **CE-EVT-R（本文）** | 理论预测的 1−ε 分位 q̂_f（修复后的 `evt_theory`） |
| **CE-EVT-R-G（本文，带门控）** | 按工况、按类别在**训练池上**选 q：理论 vs 最好的经典枢轴（见下） |

**门控规则（事先固定，只用训练池）。** 对每个 场景 × 工况 × 类别（边际 / PAC）：
1. 在训练池上做留一法：每块田作目标，从其余田块随机抽 n_cal = 25 块校准，重复 200 次。
2. 对每个候选枢轴求 λ_g。找一个公共放大系数 c，使训练池上 1[c·λ_g ≥ λ*_g] 的平均值等于 1−ε，即"代理覆盖率"匹配。
3. 计算此时的平均多出重叠。重叠只取决于计划，可以精确计算。
4. 若理论枢轴比最好的经典枢轴（原始合并、规模律；混合场景还包括规格 × 规模律）至少少 0.1 pp，就选理论；否则选那个经典枢轴。

门控在不相交的训练池上做出，对校准池和测试田块是固定函数，所以共形有效性不受影响（同 CE+ 命题 B）。

**部署上限。** λ 不得超过规划器可行上限 0.8·w/2。超出时按上限部署，这可能导致漏作业，照实计入。

## 3. 评估（解决问题 2 和 4）

- **曲线。** 对每块测试田计算"余量 → 无漏概率 / 重叠"曲线：λ 网格为 24 点，在 0.6·λ* 与 min(8·λ*, 上限) 之间按几何间隔取。每点 200 次作业，使用公共随机数，种子同 v2 阶段 B。
- **重复校准抽样。** 每个 场景 × 方法 × 类别 做 400 次独立校准抽样（n_cal = 25）。每次抽样的覆盖率为所有测试田块（混合场景为全部 45 块）P(无漏) 的平均值，多出重叠同样取平均。
- **有效性**：
  - 边际版：400 次抽样的平均覆盖率 ≥ 0.89（0.9 减去曲线的蒙特卡洛容差 0.01）；
  - PAC 版：覆盖率 ≥ 0.9 的抽样比例 ≥ 0.85（δ = 0.1，容差 0.05）。
- **效率**：每块测试田在 400 次抽样上的平均多出重叠（pp）。按田块配对的单侧 Wilcoxon 检验，对本文件全部比较做 Holm 校正，水平 0.05。
- **同等覆盖率（问题 4）。** 对每种方法求公共系数 c，使全部测试田块的平均覆盖率恰为 0.9，报告此时的多出重叠。这是次要分析，不参与主张。

## 4. 主张

**C3（理论必要性：混合机队）**
- 内容：CE-EVT-R 的平均多出重叠比**每一个**经典或数据驱动对照（原始合并、规模律、规格 × 规模律、CQR）至少少 10%，边际版和 PAC 版都要成立，且显著（Holm）。
- 有效性：CE-EVT-R 本身有效。

**C4（每格不输：同工况）**
- 内容：在 R1、R2、R3 × 边际、PAC 共 6 格中，CE-EVT-R-G 都**非劣**于最好的对照（原始合并、规模律、CQR）。即平均多出重叠 ≤ 对照 + 0.25 pp，且显著（Holm）。
- 有效性：CE-EVT-R-G 在 6 格中都有效。

**C5（事先预测提升位置，次要，报告命中率）**
- 门控选择"理论"的格子，预测 CE-EVT-R 比原始合并好 ≥ 10%。
- 门控选择经典枢轴的格子，预测没有 ≥ 10% 的提升。
- 报告 6 格（同工况）加 2 格（混合）的预测命中数。

任何一条不成立，都如实报告"不成立"。
