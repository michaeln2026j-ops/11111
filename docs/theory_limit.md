# 命题 L：一次作业/田块时跨田块 PAC 认证的信息极限

本文回答 E-low v2 中"为什么 R2 和 R3 的 PAC 格子不提升"。结论：这些格子不是方法不好，而是任何田块层面的归一化都绕不过的极限；并且第 5 层理论可以**事先**预测这个极限有多大。

## 1. 设定

- 田块 f 的单次作业分数 S 服从 G_f，真实 1−ε 分位为 λ*_f = G_f⁻¹(1−ε)。
- 校准田块 f_1, …, f_n 各有一次作业，田块从同一总体独立抽取。
- **尺度枢轴方法**：任取只依赖田块、不依赖作业数据的尺度 q_f > 0。令 V_i = S_i / q_{f_i}，t = V_(k)（第 k 个次序统计量），部署 λ_g = q_g · t。
  - 边际版：k = ⌈(n+1)(1−ε)⌉；
  - PAC 版：k 取满足 P(Bin(n, 1−ε) ≤ k−1) ≥ 1−δ 的最小值。ε = δ = 0.1 且 22 ≤ n ≤ 37 时，k = n，即取最大值（n ≤ 21 时 PAC 无解，n ≥ 38 时 k ≤ n−1）。

本文方法 CE-EVT-R（q = 理论分位）、规模律（q = √(2 log N)）、原始合并（q ≡ 1）、CQR 型特征模型都是这一类。

## 2. 命题

**命题 L（理想尺度下的余量膨胀）。** 取理想尺度 q_f = λ*_f（现实中拿不到）。记

$$H(v) = \mathbb E_f\big[G_f(v\,\lambda^*_f)\big],$$

则 H(1) = 1−ε，且部署余量与真实分位之比

$$\frac{\lambda_g}{\lambda^*_g} = t = H^{-1}(B),\qquad B\sim \mathrm{Beta}(k,\,n+1-k)$$

对所有目标田块 g 都相同。PAC 版 n = 29 时 E[B] = 29/30 ≈ 0.967。因此：

1. **膨胀由田块内部的尾部形状决定。** 若各田块归一化后的形状相同，即 G_f(v λ*_f) = Γ(v)，则 t = Γ⁻¹(B)，膨胀约为 ρ = Γ⁻¹(0.967)/Γ⁻¹(0.9)，也就是单次作业分数在 0.967 分位与 0.9 分位之比。它是执行过程的物理属性，与田块之间的差异无关。
2. **任何田块层面的预测，无论理论、特征回归还是神谕，都不能把膨胀降到 ρ 以下。** 理想尺度已经把田块之间的差异完全消除，剩下的只有田块内部的随机性。
3. **原始合并（q ≡ 1）可能比理想尺度更省。** 平均多出的重叠是 λ 的非线性函数（行数跳变）。所以当田块之间的差异小、内部尾部又重时，统一余量不一定吃亏。R3 PAC 就是这种情况：理想 +12.86 pp，原始 +10.36 pp。

**证明要点。** V_i = S_i/λ*_{f_i} 独立同分布于 H，H(1) = E_f[G_f(λ*_f)] = 1−ε。次序统计量的概率积分变换给出 H(V_(k)) ~ Beta(k, n+1−k)。目标田块的部署余量为 λ*_g · V_(k)，比值与 g 无关。第 1 点由 H = Γ 得到。第 2 点：理想尺度下比值的离散度为 0，任何其他尺度只会增加田块之间的离散，但不改变 B 的分布。第 3 点由重叠–余量映射的非线性得到，见实证。∎

## 3. 第 5 层理论事先预测这个极限

把第 1–4 层给出的 F̂_f 当作 G_f，按上式做蒙特卡洛：每块田抽一次作业，用自己的 q̂ 归一化，取 PAC 次序统计量，重复 2000 次。理论上的尾部比 ρ̂ = F̂⁻¹(0.97)/F̂⁻¹(0.9) 来自第 5 层 Gumbel 结构：q(p) = μ − β log(−log p)，所以尾部比由 β/μ 决定。

| 工况 | 理论尾部比 ρ̂ | 预测的理想 PAC 余量比（均值 ± 标准差） | v2 新田块观测值 |
|---|---|---|---|
| R1 | 1.19 | 1.30 ± 0.35 | 1.018 |
| R2 | 1.16 | 1.26 ± 0.33 | 1.207 |
| R3 | **1.54** | **1.85 ± 0.74** | **1.645** |

- 三个观测值都落在预测的 1 个标准差以内，R3 远高于 R1、R2 的排序也预测对了。
- 标准差大，是因为 n = 29 时 PAC 取最大值，单次校准抽样本身的波动就大，这一点理论同样能预测。
- 数据来源：观测值见 `results/lowdata_v2/feature_pivot.txt`，"oracle (ideal) PAC" 行；预测值由 `scripts/predict_limit.py` 给出，可复现。

## 4. 对论文的意义

- 何时有提升，由两个可事先计算的量决定：
  - **田块之间**的离散，即 λ* 的变异系数，减去理论误差：决定边际版的提升空间；
  - **田块内部**的尾部比 ρ：决定 PAC 版的下限。
- R1：田块之间的变异系数 0.087，理论误差 0.029，尾部比小，所以边际版和 PAC 版都有提升，与 C1 一致。
- R2：田块之间的变异系数只有 0.046，提升空间小，与观测一致。
- R3：尾部比 1.54，PAC 版被极限主导，与观测一致。
- 想突破这个极限，只能增加**每块田的作业次数**，或者增加**校准田块数**（n 增大时 k/(n+1) 更低）。前者改变的是数据条件，后者可以用敏感性分析定量：`scripts/matched_coverage.py` 第 3 步。
