# 事先声明（修订版 v2）：低数据实验 E-low v2

本文件在 E-low v2 的任何结果产生之前提交。

## 0. 为什么修订（v1 的结果与问题）

v1（`docs/prereg_lowdata.md`）的正式结果：预注册的 CE-EVT（PIT 枢轴）在 R1、R2、R3 都**没有**达到主张。结果原样保留在 `results/lowdata/`，论文中如实报告。

事后分析（`scripts/explore/`，与 v1 用的是同一批田块，所以是**探索性**的）发现了三个问题：

1. **理论有 bug。** 插值观测的方差误用了平稳近似，R3 有一块田得到负方差，预测 CDF 全为 NaN。v1 中这个 NaN 被排到最高位，把 R3 的 PIT 分位推到极端尾部。现已改为精确公式 Var = (1−f)²v_s + f²v_{s+1} + 2f(1−f)c_s（`evt_theory.pair_params`）。
2. **PIT 枢轴在尾部不稳。** λ = F̂⁻¹(v*) 对尺度误差的敏感度是 1/f̂(λ)，在尾部发散。改用**比值枢轴** V = S / q̂_f，其中 q̂_f 为理论预测的 1−ε 分位；部署时 λ_g = q̂_g · v*。这样反推是线性的，而理论在 1−ε 分位处恰好最准。有效性论证不变：q̂_f 只依赖田块本身，与作业数据无关，所以枢轴在田块间仍可交换。
3. **v1 的边际有效性检验设定有误。** "按田块聚类"的检验忽略了所有测试田共用同一批校准数据。给定校准集，覆盖率服从 Beta(k, n+1−k)，n = 30 时标准差约 0.05，因此 R2 上连经典方法都被误判"无效"。

**探索性结论（必须写进论文）：** 只用田块层面的理论做归一化，只能消除**田块之间**的差异。PAC 在 n≈30 时取的是近似最大值，主导它的是**田块内部、作业与作业之间**的随机性。"上帝视角归一化"（除以真实的每田最优值）在 R2 和 R3 的 PAC 上也赢不了经典方法，说明这两个格子已到信息极限。

## 1. 方法

**本文方法：CE-EVT-R（边际版、PAC 版）**
- 枢轴 V_i = S_i / q̂_{f_i}。若某块田的 F̂ 不是有限值，则令 V = +∞。这是事先固定的保守规则。
- 取 v* = conformal 分位，部署 λ_g = q̂_g · v*。
- 理论使用修复后的 `evt_theory`，其余与 v1 相同。

**对照方法**（数据完全相同）：
- 合并共形（原始分数），边际版、PAC 版；
- **规模律归一化合并共形** S/√(2 log N_f)，边际版、PAC 版。v1 把它列为消融；v2 把它**升为对照**，因为它是不需要第 1–4 层理论的最简替代，审稿人一定会问"理论到底多带来了什么"；
- 农户调参全局重叠；
- 规格重叠。

**同时报告（不参与主张）：** 修复后理论下的 CE-EVT（PIT 枢轴）；理论直接预测（无共形）。

## 2. 田块（全新）

- 每个工况用第 50–79 块，即 `core.load_fields(seed=0)` 的顺序，各 30 块。
- E-low v1 的设计和事后分析都只用了第 80 块及以后的田块。第 50–79 块只在 v8 的确认实验计划中（CE+，需要目标田数据，回答的是另一个问题），与本实验的方法选择无关。
- 采用留一法，n_cal = 29，即用其余全部田块，每块一次历史作业。

## 3. 指标与判据（固定）

**有效性**
- 有效性由定理保证：田块可交换，不依赖理论精度。合成数据上已验证（`tools/feedcar/test_feedcar.py` 与 v1 阶段 B 的合成检验）。
- 经验检查：所有测试田合并后的 P(无漏) 不低于 Beta(k, n_cal+1−k) 的 5% 分位（边际版：k = ⌈(n_cal+1)(1−ε)⌉；PAC 版：用 PAC 的 k）。该检验考虑了共用校准集的相关性。

**效率**
- 主指标：多出的重叠（pp），定义同 v1。
- 相对提升 = (对照 − 本文) / 对照。
- 如果对照的平均多出重叠 ≤ 0.5 pp，该格判为"无改进空间"，改做非劣检验：本文 ≤ 对照 + 0.25 pp。

**检验**
- 按田块配对的单侧 Wilcoxon 检验，对"工况 × 类别 × 对照方法"做 Holm 校正，水平 0.05。

**同时报告**
- 绝对重叠率；
- 新田块上的"上帝视角归一化"上界，作为信息极限的证据。

## 4. 事先预测（据 v1 探索性分析，按格写出）

| 工况 | 类别 | 对合并原始分数 | 对规模律归一化 |
|---|---|---|---|
| R1 | PAC | **提升 ≥ 10%**（探索性约 20%） | 约持平（探索性：规模律略好） |
| R1 | 边际 | 无改进空间（对照 ≤ 0.5 pp）→ 非劣 | 非劣 |
| R2 | PAC | **不提升**（田块均匀，上帝视角上界也不提升） | 不提升 |
| R2 | 边际 | 无改进空间 → 非劣 | 非劣 |
| R3 | 边际 | **提升 ≥ 10%** | 提升 |
| R3 | PAC | **不提升**（田块内部随机性主导，上帝视角上界也不提升） | 不提升 |

**主张（只有下面两条）：**
- C1：R1 PAC 比合并原始分数提升 ≥ 10%；
- C2：R3 边际比合并原始分数提升 ≥ 10%。

两条都必须在 Holm 校正后显著，且 CE-EVT-R 有效。

其余各格按预测如实报告，预测错了也照实写。
